What changed since v1, and the rules behind it

Hover PR chips, avatars and online faces for their tooltips. Everything clickable shows a pointer.

Pull request state: one chip, picked by priority

A task shows the first state below that is true for its PR, as an icon, a word and the PR number (a link to GitHub). The tooltip lists everything else that is true. A task with two PRs shows two chips.

Avatars are the defining element

People are round: a photo when they have one, initials on their identity colour when they don't. Agents are rounded squares in their role colour. When an agent works for a person, it sits on that person's avatar — pulsing while live. A green ring means online.

Four kinds of button, and links only navigate

v1 mixed a filled "Answer" with a grey "Decide" in the same list, text-only "Take over" beside a filled "Pause", and "Update branch" as a link. Now:

one per view or panel
every other action
row and toolbar actions
red text; solid only in its confirmation

Colour: four families, each with one job — fixed from v1

  • Accent blue is interaction only: primary buttons, links, focus, selected tab. v1 also used it for the "running" dot — running now uses the info tone's mark, which the design system already defines.
  • Tones are status only. v1 invented a darker red and used a grey "wait" style for an amber warning; both now come from the real tones.
  • Roles are agents only, from the real role palette. v1 invented a purple "fixer" — a fixer is an implementer, so it now wears the implementer's colour with a wrench glyph.
  • Identity colours are people only: the real eight slots, never reused for anything else. v1 approximated them.
  • One new token: merged violet, because every GitHub user reads violet as merged.

Project: its epics, with what's inside each

  • Each epic shows progress by lane, its PRs by state, who's working in it (with their live agents), what needs a person, and cost.
  • Tasks that belong to no epic sit below. The sidebar expands project → epics → tasks → agents, with a face on every row.
  • "Online" at the top of the sidebar: everyone who did anything in the last 5 minutes; hover a face for where they are.

{{if eq .Role "reviewer"}}Every finding at `medium` or above, plus `low` ones marked `trivial: yes`, is sent back to be fixed before a pull request opens; anything else goes into the pull request for a person to weigh. A conductor deciding the task may set its own bar. Mark `trivial: yes` only when the smallest fix is obvious, local and a few lines. A finding at `medium` or above states its `acceptance`; its `caused_by_fix` is `yes` when the problem is in code the last fix wrote.{{else}}Severity decides what happens next: `blocking`, `high`, `medium` send the change back to be fixed before a pull request opens; anything else goes into the pull request for a person to weigh. Rate every finding, not only failed criteria, by the same judgement as the reviewers: what happens if this merges as it is, who meets it and whether they would notice. An acceptance criterion not met is at least `high`, however small the fix. A finding at a severity that sends the change back states its `acceptance`.{{end}}

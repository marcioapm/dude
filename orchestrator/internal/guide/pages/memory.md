dude keeps a memory for each organisation: facts, procedures and notes that people, dude and agents saved, so the next piece of work starts from what is already known. One search covers that memory, the project's tasks, epics and the project itself, and this guide.

## Searching

Search finds by words and, when dude has an embedding model, by meaning too, and puts what both find first. Agents search with `search_memory` and read one result in full with `get_memory`; people search under Memory in the organisation's settings. A search can be narrowed to some types: `memory`, `task`, `epic`, `project` and `doc` (this guide).

## Remembering

An agent saves what it learned with `remember`, for its project or the whole organisation; a person adds, edits and archives memories under Memory in settings. An archived memory is no longer found.

## Who sees what

A memory belongs to its organisation, and to one project unless it is the organisation's. A brainstorm session's memories are found only by its members and its agent. The guide is the same for everyone.
